Valeurs Officielles de l'Indice Glycémique 2026

Qu'est-ce que l'Indice Glycémique ?

L'Indice Glycémique (IG) est une valeur qui indique à quelle vitesse les aliments augmentent le taux de glucose dans le sang. Contrôler l'IG est un élément clé de l'alimentation pour le diabète de type 2.

IG Bas (jusqu'à 55) — Recommandé IG Moyen (56–69) — Modéré IG Élevé (70+) — À Limiter

Comment calcule-t-on l'IG ?

L'Indice Glycémique mesure la vitesse à laquelle les glucides se décomposent en glucose. Nous utilisons l'échelle internationale (glucose pur pris comme 100 unités).

  • Mode de Préparation : Plus un produit est cuit longtemps, plus son IG augmente.
  • Fibres : Les fibres ralentissent l'absorption du sucre.
  • Acidité : Le jus de citron dans un plat abaisse légèrement l'IG.
